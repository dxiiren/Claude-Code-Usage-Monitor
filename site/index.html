Every Claude account's usage, in one widget

One small card on your Windows desktop showing the 5-hour and weekly limits of all your Claude accounts, with reset countdowns. No more logging in and out to check.

1Name your accounts

Short labels, the way you'd say them. The first one is the account you're already logged in with in Claude Code.

2Run the installer

Open Windows PowerShell (Start menu, type "PowerShell"), paste this and press Enter. You don't need Git or anything else first.

What it does, in order. It's safe to run again: it skips anything already done.

  1. Installs Claude Code and the Usage Monitor widget if they're missing.
  2. Logs in each account that isn't logged in yet (step 3 below).
  3. Builds the card with your names, sets it to start with Windows, and adds a Claude Usage shortcut.
  4. Restarts the widget and checks that every account reports live usage. Look for one [OK] line per account at the end.

3Log each account in

For each account that isn't logged in yet, the installer pauses and does this:

  1. A fresh Edge window opens with the Claude sign-in page. It shares no cookies with anything else on your PC.
  2. Sign in with that account's email and click Authorize.
  3. Copy the code the page shows, paste it into PowerShell and press Enter.
  4. The installer prints which email got logged in. Check it's the right one before moving on.
Why not just use your normal browser? Your normal browser is already signed in to your main account. It would silently log every folder in as that same account. InPrivate windows have the same problem: all open InPrivate windows share one session. That's why the installer opens its own throwaway window each time.

Everyday use

Reading the card: each row shows % used · time until reset.

under 70% 70 to 89% 90% and up (full at 100%)

On the card: drag to move it, double-click for the full dashboard, ✕ then "Close usage widget" to close it. Reopen it with the Claude Usage shortcut.

From the install folder (%USERPROFILE%\claude-usage-monitor), with just installed:

just status
Every account's email, 5-hour and weekly usage in the terminal.
just claude kv
Open Claude Code as that account.
just login kv
Log one account in again (expired, or the wrong email).
just accounts a,b,c
Change the account list and rebuild the card.
just verify
Prove every account still returns live numbers.
just start / stop
Show or close the widget.
just startup-off
Stop it starting with Windows (startup-on to undo).
just setup
Re-run the whole installer.

No just? Run powershell -ExecutionPolicy Bypass -File .\setup.ps1 in that folder instead.

Troubleshooting

An account logged in as the wrong email

Run just login <name> and sign in with the right email in the fresh window. The new login replaces the wrong one.

A row shows 100% on the weekly bar

That account has used its whole weekly allowance. The countdown next to it is when it resets. Switch to an account with a green bar: just claude <name>.

The widget shows "expired" or a row stays empty

Logins renew themselves. If one hasn't, run just login <name>, then just verify.

"running scripts is disabled on this system"

Use the command from step 2 exactly as shown. It runs through irm … | iex, which isn't blocked. For local files, use powershell -ExecutionPolicy Bypass -File .\setup.ps1.

I want the original taskbar look back

Right-click the card, open Settings, pick the Classic theme. just theme brings the multi-account card back.

Where are my tokens stored?

Only in each account's own folder on your PC (~\.claude, ~\.claude-<name>), the same place Claude Code keeps them. This kit never reads, copies or uploads them. The widget reads them locally to ask Anthropic for usage, and sends them nowhere else.
